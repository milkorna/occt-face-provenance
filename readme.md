# MCAD Test

Тестовое задание на C++ с использованием OpenCASCADE Technology (OCCT)

## Задача

Построить последовательность 3D-операций на основе плоских скетчей:

- создавать замкнутые wire и назначать уникальный ID
- выполнять выдавливание профилей
- выполнять boolean-операции (объединение и вычитание)
- отслеживать происхождение граней итоговой модели
- для каждой итоговой грани определять ID исходных wire, от которых она произошла, если такая связь существует

Проект содержит несколько примеров с последовательными extrusion и boolean-операциями, включая грани с несколькими исходными wire и грани без связанного wire

Результат также отображается во встроенном OCCT viewer с возможностью вращения модели и просмотра происхождения грани при наведении курсора

## Сборка

Проект предназначен для Windows x64 и собирается в Visual Studio с использованием C++17

OCCT подключается через `vcpkg.json`. При первой сборке требуется подключение к интернету для загрузки зависимостей, ручная настройка путей не требуется
